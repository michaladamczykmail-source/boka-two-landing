# BOKA TWO – Landing Page

Landing page sprzedażowy dla modelu **BOKA TWO** (biuro ogrodowe), stworzony jako
subdomena promocyjna dla [bokagardenroom.pl](https://www.bokagardenroom.pl/).

## Zawartość repozytorium

- `Main.dc.html` – główny plik źródłowy strony (Claude Design Components canvas:
  HTML + CSS + logika komponentu).
- `canvas.json` – konfiguracja układu (artboard) używana przy generowaniu strony.
- `boka-two-landing-page.html` – gotowy, samodzielny plik HTML strony (wygenerowany
  z `Main.dc.html`), który można hostować bezpośrednio jako statyczną stronę
  (np. na Netlify, Vercel, GitHub Pages czy dowolnym hostingu plików statycznych).
- Pliki graficzne (`*.jpg`, `*.png`) – zdjęcia i grafiki użyte na stronie.
